# Тесты API Яндекс Самокат (Praktikum)

## О проекте

Данный проект представляет собой автоматизированные тесты для REST API учебного сервиса **Яндекс Самокат**.

Проект написан с целью проверки основных эндпоинтов API:
- Создание и авторизация курьеров
- Создание заказов
- Получение списка заказов

### Технологии и язык программирования

- **Язык:** Python 3
- **Фреймворк для тестирования:** pytest
- **HTTP-клиент:** requests
- **Параметризация:** pytest.mark.parametrize
